Core Capabilities

Runtime Telemetry and Anomaly Detection Subsystems

capability-01 · process-telemetry

Kernel Syscall Telemetry Ingestion

Kernel-level eBPF instrumentation captures process execve, fork, connect, and file open syscalls in real time. Telemetry events are correlated with container metadata and spooled to the backend with sub-millisecond overhead.

Open Live Telemetry Feed →
capability-02 · anomaly-scoring

Jensen-Shannon Drift & ML Classification

Combines base-2 Jensen-Shannon distance across categorical syscall distributions with an explainable tree ensemble classifier. Evaluates 12 runtime telemetry features (drift, shell ratio, privilege escalation) with TreeSHAP feature attributions.

Inspect Scoring & ML Models →
capability-03 · vulnerability-enrichment

CVE & Exploit Path Enrichment

Static Trivy vulnerability scans are dynamically cross-referenced against runtime telemetry. Only vulnerabilities whose affected binaries are actively executed or listening on open ports are escalated to high-priority triage.

View Vulnerability Matrix →
capability-04 · containment-response

Autonomous Containment & Audit

When anomaly severity exceeds operator thresholds, the responder executes automated containment: pausing workloads, severing network bridges, or killing processes, while recording complete forensic timelines.

Research Architecture

Deterministic & Reproducible

Porygon establishes an empirical framework for container runtime security. The platform instruments Linux kernel syscalls via eBPF probes, calculates Jensen-Shannon categorical drift distributions, and classifies deviations with TreeSHAP explainability across open benchmark datasets.

Architecture Philosophy

Observable by Default

Every component follows strict capability modeling (process-telemetry, event-ingestion, vulnerability-enrichment, containment-response). All events carry structured metadata, all API responses include system info envelopes, and every automated action leaves an immutable audit trail.
